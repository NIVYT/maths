## ✨ Features

- **Built for First-Timers & Fast Revision**: Complete ground-up explanations, definitions, intuitive models, and formula reference sheets.
- **Graded Worked Examples**: Easy $\to$ Medium $\to$ Hard level problems with step-by-step reasoning.
- **NCERT Exercise Solutions**: Step-by-step worked solutions for key textbook problems inside interactive collapsible toggles.
- **Common Traps & Pitfalls**: Warning cards highlighting the most frequent silly mistakes that cost marks in exams.
- **Self-Check Quizzes**: Quick 5-question active recall tests at the end of each chapter with expandable answers.
- **Clean Aesthetic**: Always light theme with solid colors, zero emojis (pure SVGs), no heavy borders, and full KaTeX mathematical typesetting.
